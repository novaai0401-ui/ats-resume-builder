CallbackCV — Extension Settings

Recommended: connect from the website

Sign in to CallbackCV, then open the Connect page and click “Connect my extension.” Your token is handed to the extension securely — no copy-pasting.

Manual setup (power users)

The URL of the CallbackCV API server. Production deployments use the public HTTPS URL.

In the web app: DevTools → Application → Local Storage → key accessToken. The token stays in chrome.storage.local and never leaves your machine except to authenticate API calls.
